# Resume Bullets: Portfolio Copilot System

- Built a production-oriented portfolio and private AI job copilot with Next.js, TypeScript, Prisma/PostgreSQL, Tailwind, local tailoring workflow, and a local Playwright apply agent.
- Designed a hidden copilot workflow with secure access-key handling and an apply agent that prepares applications while pausing before submission.
- Prepared a GitHub-safe release by excluding local secrets, build caches, npm caches, dependency folders, and logs.
