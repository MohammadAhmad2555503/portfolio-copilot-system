# Portfolio Card: Portfolio Copilot System

**Repo:** portfolio-copilot-system

**One-liner:** Production-oriented portfolio and private AI job copilot built with Next.js, TypeScript, Prisma, PostgreSQL, Tailwind, local tailoring workflow, and a local apply agent.

**Tech:** Next.js, TypeScript, Prisma, PostgreSQL, Tailwind CSS, Framer Motion, structured workflow design, Playwright, Automation Safety

**Best proof points:**
- Public portfolio plus hidden copilot dashboard in a Next.js application.
- Prisma/PostgreSQL data model and seed workflow for project/job-copilot data.
- Separate local Playwright apply agent designed to prepare applications and pause before submission.
- Privacy-safe upload excludes .env, Next build cache, npm cache, node_modules, logs, and runtime files.
